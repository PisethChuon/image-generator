# Image generation with Image Playground
Built a macOS app that generates images of food using programmatically created prompts.
You included interactive features to refine the images by adding and removing ingredients.


### Topics and skills covered
- Creating SwiftUI apps for macOS
- Generating images with Image Playground
- Specifying image styles with ImagePlaygroundStyle
- Customizing generated images with ImagePlaygroundConcept
- Showing loading progress with ProgressView
- Iterating sequences over time with AsyncSequence
- Adding menu bar commands
- Providing keyboard shortcuts
